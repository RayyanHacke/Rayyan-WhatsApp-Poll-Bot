2. **8-Digit Pairing Code Authentication:** No need for a second phone or QR code scanner! Connect your WhatsApp directly on a single Android device via Termux.

4. **JSON Bulk Poll Loader:** Supports loading pre-configured quiz banks directly from `mcqs.json`.
5. **Automated Message Sender / Repeater:** Send custom text notifications or reminders to a specified number with configurable repeat counts and safety intervals.
6. **Live Group Target Switcher:** Switch between different study groups on the fly without restarting or editing the source code.
7. **Multi-Account Session Manager:** Unlink the current WhatsApp session and pair a new phone number directly from Button `[5]`.
8. **Built-in Anti-Ban Delay Engine:** Enforces a smart 12-second cooldown between consecutive polls and 2.5 seconds between messages to protect your account from spam detection.
